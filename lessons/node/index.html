Node

The guardians of Bitcoin's truth

What a Bitcoin node does, why running one makes you sovereign, and how a $75 computer verifies a trillion-dollar system. This is the reading version - the interactive lesson has the live demos, quizzes, and progress tracking.

Start the interactive lesson →

A Bitcoin node is simply any computer running the Bitcoin software and participating in the network. Think of it like a volunteer fact-checker in a massive, decentralized jury. Your node downloads a copy of every single Bitcoin transaction ever made - the full history going back to 2009 - and verifies that every new block follows all of Bitcoin's rules.

There are currently tens of thousands of nodes spread across the globe. Some people run nodes on a Raspberry Pi. You don't earn money for running a node (that's mining's job) - you run a node because you want to verify for yourself that Bitcoin is working as designed.

A full node downloads every block since the genesis block. A pruned node verifies everything but discards old blocks. A light node trusts other nodes - useful for mobile wallets.

Nodes are Bitcoin's immune system. They enforce the rules, make sure miners can't cheat, and ensure the 21 million supply cap is never broken. Every node you add makes the network stronger.

Key terms

verify for yourself
"Don't trust, verify" is a Bitcoin motto. Running your own node means you never have to trust anyone else's word about what's in the blockchain.
full node
A node that downloads and verifies the ENTIRE blockchain from the beginning (currently about 600+ GB). Maximum security and privacy.
pruned node
A full node that verifies everything but discards old blocks to save space. Less storage, still high security.
light node
Also called SPV. Trusts other nodes rather than verifying everything itself. Faster but requires more trust.
