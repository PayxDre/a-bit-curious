Private Keys

The secret that controls everything · ~4 min read

What makes a private key safe: 256 bits of real entropy, and why bad randomness has been robbed before. This is the reading version - the interactive lesson has the live demos, quizzes, and progress tracking.

Start the interactive lesson →

A Bitcoin private key is just a number between 1 and 2²&sup5;&sup6;. There are roughly 2²&sup5;&sup8; atoms in the observable universe. Your private key is a random point in a space almost as vast. It's impossible to guess someone's private key - even if every computer ever built worked on it together for longer than the universe has existed.

Private keys are generated from entropy. The key is encoded in WIF for human readability.

This is the part nobody checks and everybody depends on. Your key is only unguessable if the randomness behind it was genuine - and in July 2026 a firmware bug in Coldcard hardware wallets quietly replaced the chip's true random number generator with a predictable one, leaving thousands of seeds guessable and around 1,367 BTC swept from wallets that were never otherwise touched.

🕶 The Size of the Keyspace

2256 = 115,792,089,237,316,195,423,570,985,008,687,907,853,269,984,665,640,564,039,457,584,007,913,129,639,936

possible private keys. More than atoms in the observable universe. Unguessable.

The private key is what you use to sign transactions. The signature proves you authorized it but never reveals the private key itself. It's like proving you own a special pen without ever showing the pen.

A private key should never be typed into a website, shared in a message, stored in cloud storage, or photographed. Hardware wallets keep the key on a specialized chip that never connects to the internet - even when signing, the private key never leaves the device.

Key terms

entropy
Randomness from unpredictable sources - mouse movements, keyboard timings, hardware noise. Bad randomness is one of the rare ways Bitcoin security has been compromised.
WIF
Wallet Import Format - encoding a raw key as a shorter, error-checked string starting with "K", "L", or "5".
