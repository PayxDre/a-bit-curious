Public Keys

The ID card you CAN share safely

One-way cryptography you can feel: derive addresses instantly, then try to reverse one and see why you cannot. This is the reading version - the interactive lesson has the live demos, quizzes, and progress tracking.

Start the interactive lesson →

A public key is derived from your private key using elliptic curve multiplication. Think of it like mixing paint: starting with a secret color, you apply a recipe to get a new color. Anyone can see the result, but they can't figure out the original.

Public keys are 33 bytes (compressed). From your public key, your address is derived via SHA-256 then RIPEMD-160.

Two hash functions = double protection. Even if one breaks, the other protects you.

Public keys are safe to share. After spending from an address, your public key is revealed, so best practice is to use each address only once for privacy.

The relationship: private key is your identity proof, public key is your verifiable credential, address is your shareable contact info. None of this requires a passport, a bank account, or anyone's permission.

Key terms

elliptic curve multiplication
A mathematical operation on the secp256k1 elliptic curve. You take a generator point and add it to itself (private key) times. Fast to do, impossible to reverse.
SHA-256
Secure Hash Algorithm 256-bit - converts any input into a unique 32-byte fingerprint.
RIPEMD-160
Another hash that shortens the output to 20 bytes. Two different hash functions provide extra security.
