Bitcoin Network

A global web of computers with no boss

The peer-to-peer network no one can switch off: how transactions propagate and why there is no headquarters. This is the reading version - the interactive lesson has the live demos, quizzes, and progress tracking.

Start the interactive lesson →

Imagine if, instead of one big central bank keeping track of everyone's money, millions of ordinary computers around the world all kept a copy of the same record book simultaneously. That's exactly what the Bitcoin network is. It's a peer-to-peer network, which means there's no head office, no CEO, no single computer running the show.

The Bitcoin network has been running continuously since January 3, 2009.[26] In that time, it has never been successfully hacked, never gone down for more than a few minutes, and has processed trillions of dollars in transactions. To attack Bitcoin, you'd need to simultaneously overpower more than half of all the computers on the network - called the 51% attack threshold.

Every time you send Bitcoin, your transaction is broadcast to the entire network. Thousands of computers hear it, verify that you actually have the coins, and then agree to record it permanently. This process of agreement is called consensus. No single computer can lie, because everyone else would reject the lie immediately.

The beauty of this system is that it needs no trust. The rules of Bitcoin are enforced by mathematics and code, not by humans. Anyone can join the network, anyone can leave, and the system keeps working perfectly regardless. It's the most resilient financial network ever built.

Key terms

peer-to-peer network
A network where every participant is equal - there's no central server or controller. Every computer talks directly to other computers. Think BitTorrent, but for money.
51% attack threshold
To cheat the Bitcoin network, you'd need to control 51% of all its computing power simultaneously. At current network size, this would cost billions of dollars and is practically impossible.
consensus
The process by which all computers on the Bitcoin network agree on the same version of truth. It's democracy for computers - majority rules, and the majority is always honest.
