Difficulty

Bitcoin's self-balancing superpower

Bitcoin retunes its own difficulty every 2,016 blocks. Shock the network in a simulator and watch it heal. This is the reading version - the interactive lesson has the live demos, quizzes, and progress tracking.

Start the interactive lesson →

No matter how many miners join or leave, a new block is always found approximately every 10 minutes. Bitcoin has a built-in difficulty adjustment that recalibrates every 2,016 blocks (~two weeks).

Think of it like a school exam that automatically adjusts. If too many students get answers too quickly, questions get harder. If students drop out, questions get easier. No one is in charge.

The difficulty is expressed as a target hash. The entire network's combined guessing speed is called the hash rate.

Every 2,016 blocks, Bitcoin auto-adjusts to keep blocks at ~10 minutes. No human decides this.

The difficulty mechanism is one of Bitcoin's most elegant inventions. It means Bitcoin cannot be "sped up" by adding more computing power. The 10-minute block time is maintained through pure mathematics.

OK, but can it be attacked?

You understand how Bitcoin works. Now let's stress-test it - every attack vector people have imagined, and why the system makes each one economically irrational.

Key terms

difficulty adjustment
Every 2,016 blocks (~2 weeks), Bitcoin automatically measures how fast blocks have been coming in and adjusts the puzzle difficulty.
target hash
A valid block hash must be smaller than this target. Currently, a valid hash must start with ~20+ zeros - astronomically rare.
hash rate
Currently hundreds of Exahashes per second. One Exahash = one quintillion hashes per second.
